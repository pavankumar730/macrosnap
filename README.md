# MacroSnap 🥗

A Streamlit chat app where you enter your name and WhatsApp number, then chat with an AI nutrition buddy — type a question or send a meal photo — and get an instant calorie and macro estimate. One click sends a summary straight to WhatsApp.

Built with **Gemini** (chat + vision) and **Twilio** (WhatsApp).

## Setup

1. Clone this repo
2. Create and activate a virtual environment
3. Run `pip install -r requirements.txt`
4. Copy `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml` and add your own Gemini and Twilio keys
5. Run `streamlit run app.py`
